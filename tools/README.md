# Инструменты

Небольшие утилиты, которые помогают проверять материалы курса на практике.

- [Расширение «Все cookie»](cookie-viewer.md) — вкладка DevTools со всеми cookie домена и поддоменов
  с любым `Path`, включая `HttpOnly`.
